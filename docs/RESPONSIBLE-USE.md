# Responsible use

OpenSeek is free, self-hosted software for sharing NVMT packages through a Telegram-backed pool. Nuvio can create packages locally during playback. An owner can also start package generation from the OpenSeek dashboard.

OpenSeek maintainers do not run users' pool servers, provide video downloads, or operate a central content service. Each pool owner controls access to their Telegram channel and the devices that can read or write packages.

You must hold the rights, permissions, or applicable legal exceptions needed to create and share packages from media you access. You are responsible for the sources used for dashboard generation and for the people you authorize to use your pool.

This notice does not remove anyone's legal responsibility and is not legal advice. Technical privacy features do not change the rules that apply to your use.
